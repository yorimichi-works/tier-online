# 繁体字中国語（台湾）ローカライズ監査

## ロケール方針

- UIロケール: `zh-TW`（Flutter内部では `AppLocale.zhTw`）
- URLコード: `zh-tw`
- `hreflang`: `zh-Hant-TW`
- OGP locale: `zh_TW`
- 既定地域: `TW`
- 台湾、または `zh-Hant` の端末を繁体字UIへ振り分ける
- UI言語とTier投稿の原文言語は別概念として維持する

## 洗い出し・対応済みの範囲

- Flutter固定文言336キー（認証、作成、検索、ランキング、コメント、通報、共有、エラーを含む）
- 日本語UI上の言語名（日本語・韓国語・英語・繁体字）と各UI言語から見た言語名
- Flutter `supportedLocales`、端末判定、保存値、URL解析
- 台湾地域 `TW` の選択肢と既定値
- 世界のTierにおける繁体字投稿の表示・複数言語選択
- 繁体字の動物・国・食べ物クイックテンプレート
- 利用規約、プライバシーポリシー、問い合わせ画面の固定文言
- 日本語・韓国語・英語・繁体字の混在表示用フォントフォールバック
- 言語別ブランド表示（専用画像がない間は英語ロゴを使用）
- Web初期ローディング表示、HTML title、description、OGP、`lang`
- `/zh-tw/` と `/zh-tw/tier/{id}` のFirebase Hostingルーティングとキャッシュ制御
- Cloud Functionsの画像検索locale、繁体字Wikipedia検索
- 確認メールの繁体字件名・本文・ボタン・遷移URL
- SEO Functionsのcanonical、alternate、OGP、sitemap
- READMEと将来自動翻訳設計の4言語化

## 自動検証

- 繁体字辞書と英語辞書のキー集合が完全一致するテスト
- `zh-TW` の端末・URL判定テスト
- `/zh-tw/` の画面描画と狭幅レイアウトテスト
- 日本語UIで「韓国語・英語・繁体字」と表示される言語フィルターテスト
- 繁体字を含むCJK混在文字列とフォントフォールバックテスト
- 繁体字確認メールのテスト

## 画像資産

繁体字専用ロゴと横長OGP画像は未提供のため、UIロゴは既存英語ロゴ、OGPは言語非依存のアプリアイコンを使用する。これにより日本語・韓国語・英語の文字入り画像を繁体字ページへ誤表示しない。専用画像を追加する場合は `common_widgets.dart`、`seo.ts`、`web/index.html` の参照を同時に更新する。
